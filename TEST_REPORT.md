# Отчёт о тестировании

## Выполнено (Linux, Python 3.13, `python -m pytest`: 117 passed)
Модульные тесты ядра с поддельным yt-dlp и поддельными источниками обновлений: обновление/откат/автооткат компонентов, запрет замены при активных загрузках,
контрольные суммы, очередь (пауза/отмена/повтор/параллельность/дубли), построение форматов, разбор прогресса, классификация ошибок, редактирование секретов,
миграция настроек, диагностика. Смоук-тест интерфейса — **на заглушках Qt** (проверяет согласованность с бэкендом, не Qt).

## НЕ проверено (нужна Windows/сеть)
Запуск окна; реальные загрузки YouTube/Shorts/возрастные; авторизация Firefox; ошибка Chrome DPAPI; MP4+FFprobe на реальных файлах;
обновление yt-dlp/EJS/Deno/FFmpeg из сети; установка поверх v5.1; запуск без Python; Windows 10/11; Instagram, TikTok, Facebook, X, Reddit.

## Локальный сценарий (PowerShell, на вашем ПК)
1. Установить установщик поверх F:\VideoDownloaderStudio; запустить; «Диагностика → Полная диагностика».
2. «Компоненты» → «Проверить все» → «Обновить все»; затем «Откатить» yt-dlp и снова обновить.
3. «Авторизация» → YouTube → Firefox → «Проверить авторизацию».
4. Скачать https://www.youtube.com/shorts/U8nrRMitpWI (MP4, макс. качество); проверить, что файл открывается; запустить 3 ссылки сразу; отменить одну; повторить ошибочную.
5. Убедиться, что прежние папка загрузок и настройки сохранились.
