# Video Downloader Studio 6

Windows-приложение (PySide6) для загрузки видео через yt-dlp. Интерфейс на русском.

**Что нового в 6.0:** yt-dlp, EJS, Deno и FFmpeg/FFprobe — отдельные обновляемые компоненты (раздел «Компоненты и обновления»),
менеджер авторизации (Firefox, Chrome, Edge, Brave, Opera, cookies.txt), очередь с параллельной загрузкой, история,
автоматическая диагностика ошибок на русском, раздел «Диагностика» с экспортом TXT/JSON, миграция настроек v5.x.

## Установка
Скачайте `VideoDownloaderStudio-Update-Windows-x64-Setup.exe` из GitHub Releases / артефактов Actions и запустите.
Можно выбрать папку (например `F:\VideoDownloaderStudio`) — установка идёт поверх прежней версии. Python не нужен.
Настройки, история и компоненты лежат в `%APPDATA%\VideoDownloaderStudio` и `%LOCALAPPDATA%\VideoDownloaderStudio`
и не удаляются ни при обновлении, ни при удалении программы; скачанные видео не затрагиваются.

## Запуск из исходников
```
pip install -r requirements-dev.txt
python app.py
python -m pytest
```
Сборка установщика: см. BUILD_WINDOWS.md. Восстановление: при проблемах после обновления откатите компонент кнопкой
«Откатить обновление» или установите прежний установщик поверх — данные пользователя сохранятся. Прежний код v5.1: `backup/v5.1/`.

Используйте программу только для контента, на скачивание которого у вас есть право. Пароли не сохраняются, cookies не попадают в журналы и отчёты.
