# Известные ограничения
- Окно не запускалось в среде разработки (нет PySide6/Windows): возможны ошибки интерфейса, которые найдёт только реальный запуск.
- Установщик собран в GitHub Actions (Windows runner), но не установлен и не проверен на реальной машине.
- В CI на Windows пропускаются тесты, использующие shell-скрипты как поддельные exe (test_engine, test_components и 2 отдельных теста) — они выполняются только на Linux.
- Работа платформ (кроме проверенной пользователем YouTube Shorts через CLI) не подтверждена тестами.
- Chrome/Edge/Brave: ошибки DPAPI/блокировки cookie-базы — используйте Firefox или cookies.txt.
- Новая сборка кладёт файлы в `_internal` рядом с exe; старые файлы там (в т.ч. FFmpeg v5.x) остаются и используются как запасной вариант.
- Исходный `media_backend.py` и тесты из первого архива в репозитории отсутствуют.
