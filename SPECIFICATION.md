# Спецификация (v6.0)

Исходное ТЗ: обновление существующего приложения без потери функций. Архитектура:

| Модуль | Назначение |
|---|---|
| `vds/components.py` | Менеджер компонентов: официальные источники (GitHub yt-dlp, denoland, BtbN, nodejs.org), SHA-256, staging → проверка → активация, бэкап и автооткат, запрет замены во время загрузки, история |
| `vds/engine.py` | yt-dlp запускается как **отдельный процесс** (версия не привязана к приложению), разбор прогресса, FFprobe-проверка, совместимость MP4 |
| `vds/jobqueue.py`, `vds/store.py` | Очередь (параллельность, пауза, отмена, повтор, восстановление), история SQLite, защита от дублей |
| `vds/auth.py` | Обнаружение браузеров/профилей, cookies.txt (Netscape), проверка входа без вывода значений cookies |
| `vds/errors.py` | 20+ типов ошибок: описание, причина, решение, повтор, технические подробности |
| `vds/diagnostics.py` | Полная диагностика, экспорт TXT/JSON с редактированием секретов (`vds/redact.py`) |
| `vds/config.py` | Настройки схемы 2, миграция из v5.x, резервные копии |
| `vds/gui.py` | Интерфейс: загрузка, очередь, история, авторизация, компоненты, диагностика, настройки, журнал |

Порядок поиска компонента: управляемый (обновлённый) → встроенный в установщик (берётся более новый) → старая папка `_internal` (FFmpeg) → PATH (только по настройке).
Stable — по умолчанию; Nightly — по выбору (только yt-dlp). Автопроверка обновлений при запуске отключаема.
